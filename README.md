## Mein Arbeitsablauf mit Git

So bringe ich Änderungen in mein Repository:

```bash
git checkout -b mein-branch
git add .
git commit -m "Beschreibung der Änderung"
git push origin mein-branch
```

Danach öffne ich auf GitHub einen Pull Request und führe die Änderungen mit `main` zusammen.

## IPT1-Lernnachweis

**Was habe ich gelernt?**
Ich habe gelernt, ein Repository auf GitHub anzulegen, einen Branch zu erstellen, Dateien hochzuladen und die Änderungen per Pull Request in `main` zu übernehmen.

Das man es sehr gut verwenden kann wen man die Basics versteht.
